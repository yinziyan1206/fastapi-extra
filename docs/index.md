# fastapi_extra Documentation

`fastapi_extra` is an enterprise-grade enhancement extension library for **FastAPI** (Python >= 3.12, BSD-3-Clause). It builds on top of vanilla FastAPI and ships with production-ready components for database, caching, task scheduling, unified responses, and dependency injection.
